# SMC 基线系列 —— R2023b 复现说明

> 本目录由 R2024b 的 `save_system(..., 'ExportToVersion', 'R2023b')` 导出，
> 可在 **MATLAB/Simulink R2023b 及以上**直接打开。与论文 §3.4 / §5.1 / §5.2 /
> §5.5 / §5.6 / §5.7 的 SMC 对应。

## 一、文件清单

| 文件 | 说明 |
|---|---|
| `smc_step.slx` | 阶跃工况闭环（R2023b 格式） |
| `smc_circle.slx` | 圆轨迹工况闭环（R2023b 格式） |
| `smc_aug.m` | 边界层切换项 `tau_sw = -RHO .* sat(z2/PHI)`（版本无关） |
| `rovmodel75kg.mat` | 75 kg 基准模型参数（M、Ma、DL、W 等） |
| `README_SMC_R2023b.md` | 本说明 |

模型 PreLoadFcn 会自动执行 `S=load('rovmodel75kg.mat'); M_nom=S.M; ...`，
因此 **smc_aug.m / rovmodel75kg.mat 必须与 .slx 同目录**（本目录已满足）。

## 二、运行前必做（base 工作区）

```matlab
cd <本目录>                       % 必须切到本目录, PreLoadFcn 按相对路径找 mat
RHO_SMC = [10;10;10;2;2;2];      % 最优整定 (论文 §3.4 调参网格最优)
PHI_SMC = 1.0;                   % 边界层厚度
```

> `smc_aug.m` 每步从 base 读 `RHO_SMC`/`PHI_SMC`（全列向量），扫参时直接改这两个变量。

求解器设置：**ode45，MaxStep = 1e-3 s**，StopTime：阶跃 100 s / 圆轨迹 100 s。

## 三、各工况复现

| 工况 | 操作 | 论文位置 |
|---|---|---|
| 阶跃标称 | 打开 `smc_step.slx` 直接运行 | §5.1 |
| 圆轨迹标称 | 打开 `smc_circle.slx` 直接运行 | §5.2 |
| 恒定海流 0.3 m/s | 模型内海流注入块使能/置值；**MaxStep 改 5e-4**（1e-3 有零穿越伪影） | §5.6 |
| 慢变海流 0.2+0.1sin(0.05t) | 同上，改慢变剖面 | §5.6 |
| 失配 +60% | 控制器侧 M/Ma/DL 各 ×1.6（PreLoadFcn 赋值后覆盖 M_nom/Ma_nom/DL_nom） | §5.5 |
| 失配 +20%/+40% | 同理 ×1.2 / ×1.4 | §5.5 |
| 失配 −20%/−40% | ×0.8 / ×0.6（−60% 会发散，属正常现象） | §5.5 |
| 量测噪声 | 在 η 量测线串接 Band-Limited White Noise（乘 σ 后叠加） | §5.7 |
| 推力饱和 ±50 V | 在 u 输出级串接 Saturate（上下限 ±50） | §5.7 |

### ⚠️ R2023b 与 R2024b 的参数名差异（噪声块）

| 参数 | R2024b | R2023b |
|---|---|---|
| 噪声功率 | `Cov` | `NoisePower` |
| 采样时间 | `Ts` | `SampleTime` |
| 种子 | `seed` | `Seed` |

若用脚本配置噪声块，R2023b 下必须用右列参数名（手改对话框则无影响）。

## 四、验收参考值（R2024b 实测，R2023b 应高度接近）

| 量 | 数值 |
|---|---|
| 阶跃稳态 RMS (x/y/z) | 0.3967 / 0.4037 / 0.3246 m |
| 阶跃 rise (x/y/z) | 24.22 / 31.97 / 37.77 s |
| 阶跃 settle / overshoot | 无定义（稳态卡在目标下方 15.8–19.9%，表 4 中为 "—"） |
| 圆轨迹全程 RMS | 0.9245 m（xy 0.7077 / z 0.5948） |
| 恒定海流全程 RMS | 0.9303 m（MaxStep 5e-4 口径） |
| +60% 失配圆轨迹 | 0.7912 m（比标称改善，过估方向更稳） |
| 噪声/饱和 | 不失稳；饱和下 +1.3% |

> 注：圆轨迹类全程 RMS 含抓取瞬态，对求解器/版本敏感（论文正文已注明采用
> R2024b 单环境口径）；阶跃稳态指标对版本不敏感。R2023b 复现若圆轨迹 RMS
> 与 0.9245 有百分之几的偏差属正常，量级与结论（劣于纯反步 0.7862、受切换
> 项拖累）应完全一致。
